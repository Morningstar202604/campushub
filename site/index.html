核心功能

学生日常，一个社区全覆盖

八个内容分类 + 四个发布场景，从二手交易到匿名表白，高频场景开箱即用。

信息流与分类

二手闲置、失物招领、表白墙、课程学习、校园活动、兼职实习、拼车拼团、闲聊树洞八分类，推荐 / 最新 / 热榜三种排序。

校园市集

二手商品网格、价格与成色标注、面交引导、防诈骗提示。毕业季清仓、开学季淘货都能用。

四场景发布

发帖子、卖闲置、失物招领、匿名表白墙，独立表单 + 图片上传，发布后立刻出现在信息流。

全局搜索

帖子 + 商品统一检索，数据库级模糊匹配，输入关键词秒出结果。

校园指南

新生入学、生活贴士、学习攻略等 Markdown 富文本文档，分类导航即点即读。

签到与积分

每日签到 +1 积分，连续 7 天额外奖励。配套个人中心、消息通知、意见反馈闭环。

技术栈

学生端 H5 框架，Pinia 状态管理

国内云托管

阿里云 / 火山 / 腾讯 Supabase，免自建服务器

快速开始

三步部署，零服务器

先看效果：mock 演示模式一条命令跑起来；正式上线走下面的流程。

01

开通 Supabase

国内云任选（阿里云 RDS / 火山 / 腾讯云），新建项目拿到 URL 和 anon key。

02

执行数据库脚本

依次运行 packages/db/schema.sql 与 seed.sql，17 张表 + 权限 + 种子数据一步到位。

03

配置并构建

学生端填环境变量构建部署到静态托管，管理后台同项目登录即用。

cd apps/web && npm install && VITE_USE_MOCK=true npm run build 无需任何后端配置，打开即可体验全部功能
