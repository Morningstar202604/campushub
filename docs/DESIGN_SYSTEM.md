# DESIGN_SYSTEM — 去 AI 味视觉体系「墨荧 · Acid Campus」

> 诊断：现状 = TDesign 默认蓝 `#0052d9`（硬编码 94 处）+ 通用蓝 `#4A90D9` 两套色系打架，
> 白底圆角卡片 + emoji 空态——标准的「模板味 / AI 味」。
> 本文档定义一套有性格的视觉体系，随 uni-app 迁移（P0 阶段）以 `tokens.scss` 落地。

---

## 一、设计立场（先立规矩，再谈颜色）

**性格关键词：墨夜 × 荧光 × 校园地下文化。**
表白墙、二手市集、失物招领——这些是校园的"夜生活"，天然适合暗色海报美学，
而不是白底蓝按钮的"办公软件脸"。

### 反 AI 味铁律（评审时逐条对照）

| # | 铁律 | 违例示例（禁止） |
|---|---|---|
| 1 | 禁默认蓝/紫，禁蓝紫渐变 | `#0052d9`、`#7C5CFF`、紫罗兰 hero 渐变 |
| 2 | 禁 emoji 当空态/图标 | 空态一个 😢 + "暂无数据" |
| 3 | 空态用「文字海报」：大字重短句 + 荧光点缀 | "这里空空如也" |
| 4 | 圆角只许两档：**8rpx（锐）** 与 **28rpx（胶囊）**，禁止满屏 16rpx 中庸圆角 | 所有卡片一个圆角 |
| 5 | 无软投影。用 **1px 硬边框** 或 **`0 4rpx 0` 硬投影**（海报/贴纸感） | `box-shadow: 0 4px 12px rgba(0,0,0,.08)` |
| 6 | 字重拉满对比：标题 **900** vs 正文 **400**，中庸的 600 禁用 | 全页 500/600 一刀切 |
| 7 | 深色为默认主题，浅色是"打印版" | 浅色为主、深色当附属 |
| 8 | 每页只允许**一个**荧光色焦点（价格/CTA/未读点），多荧光=廉价霓虹灯 | 整页全是荧光色块 |

### 备选方案（不满意 A 再看这两个）
- **方案 B「 Polaroid 市集」**：暖纸白 + 焦糖橙 `#E8590C` + 钴蓝点缀，日系胶片感，浅色为主。

## 三、字体与版式

| 层级 | 规格 |
|---|---|
| 页面大标题 | 40rpx / **weight 900** / 字间距 -0.5rpx |
| 卡片标题 | 30rpx / **weight 900** |
| 正文 | 28rpx / weight 400 / 行高 1.65 |
| 数字（价格/积分/计数） | **等宽数字** `font-variant-numeric: tabular-nums` + accent 色 |
| 字体栈 | `HarmonyOS Sans, MiSans, PingFang SC`（系统栈，不引字体文件） |

**版式签名动作**（品牌记忆点，全站复用）：
荧光色**斜切角标签**（`clip-path: polygon` 切掉一个 8rpx 角）用于「已售/置顶/过期」等状态标——比圆角小药丸有性格得多。

## 四、组件级规范（旧版痛点逐个修）

| 组件 | 新规范 |
|---|---|
| tabBar | 深色底 + 荧光选中态；选中图标做 15% 上浮动效 |
| 表白墙卡片 | 深底 + 硬边框 + 内容超 3 行渐隐；匿名帖显示「硬币压角」效果（卡片右上角斜切） |
| 商品价格 | tabular-nums + accent 荧光色 + `¥` 符号小一号 |
| 空态 | 大字重短句 + 一个荧光色几何符号（●▲■），禁 emoji |
| 骨架屏 | 保留现有 skeleton，色值换 `#1D241F` 底 + `#2A322C` 块 |
| 按钮 | 主按钮 = 荧光底 + 墨黑字（weight 900）；次按钮 = 透明底 + 1px 边框 |
| 签到/积分 | 数字翻牌动效，accent 色，打卡成功全屏荧光闪 200ms |

## 五、落地方式

1. `styles/tokens.scss` 定义上表全部令牌（唯一事实源），wot-design-uni 的主题变量全部指向令牌；
2. 迁移期**先功能后换肤**：P0 先落 tokens，P2-P4 迁页面时直接用新令牌写样式（不留旧色）；
3. 旧仓的 94 处 `#0052d9` 硬编码在 uni-app 重写中自然消失，不做兼容层；
4. 深浅色切换：`uni.onThemeChange` + CSS 变量双套值，用户可锁深色。

## 六、视觉验收清单

- [ ] 全仓 grep 无 `#0052d9` / `#4A90D9`（旧蓝归零）
- [ ] 每页荧光焦点 ≤ 1 个
- [ ] 圆角只出现 8rpx / 28rpx 两档
- [ ] 全站无 emoji 空态/图标
- [ ] 文本对比度 ≥ 4.5:1（tertiary 仅限 ≥32rpx 大字）
- [ ] 深浅两套主题截图对比通过
- [ ] 「斜切角标签」在 ≥3 类组件复用（品牌一致性）
