# CampusHub 成本与云服务选型指南

> 回答一个高频问题：「能不能用 Cloudflare 等免费云服务替代微信云开发？」
> 结论先行：**不能（合规硬墙），也不需要——微信云开发自带免费额度正好覆盖开发阶段。**

---

## 一、为什么不能把后端搬到 Cloudflare

### 1.1 ICP 备案是硬门槛

微信小程序「request 合法域名」的官方要求：**域名必须经过 ICP 备案，且备案主体需与小程序主体一致。**

- Cloudflare 域名（含 `*.workers.dev`）注册在境外，**无法完成 ICP 备案**
- 把 `https://xxx.workers.dev/api` 填进小程序后台 → 直接被拒
- 「业务域名」（webview 用）同样要求备案，且**个人主体不支持该功能**

### 1.2 就算绕过备案，改造也劝退

CampusHub 全部后端长在 wx.cloud 上：**37 个云函数 / 21 个集合 / 41 个索引 / 2 个定时触发器**。迁移到 CF（Workers + D1 + R2）意味着：

| 现状（wx.cloud，零成本享有） | 迁 CF 要做的 |
|---|---|
| 37 个云函数 | 全部重写为 Workers 路由 |
| 21 个集合（文档型） | 迁 D1（SQL），字段模型重设计 |
| 云存储图片 | 迁 R2，自己写上传签名 |
| `getWXContext()` 免费拿 openid | 自己实现 code2Session + session 管理 |
| msgSecCheck/imgSecCheck 免鉴权 | 自己维护 access_token 轮换 |
| 2 个定时触发器 | Cron Triggers 重写 |

为省每月十几块付出数周改造 + 长期运维复杂度，**不划算**。

### 1.3 唯一例外：微信云托管

微信云托管的 `callContainer` 调用**豁免域名备案**（流量走微信内部通道），可跑 Docker 容器。如将来想脱离云开发函数但留在微信生态，可作备选。它按量计费且同样需要迁移代码——现阶段不动。

### 1.4 Cloudflare 真正能免费用的地方：落地页

小程序本体进不去 CF，但**普通浏览器打开的网页不受备案限制**。仓库根目录的 `index.html` 落地页可用于对外宣传（公众号文章 / README / 二维码进浏览器）：

```bash
# 方式一：Wrangler CLI（需 Cloudflare 免费账号）
npm i -g wrangler && wrangler login
wrangler pages deploy . --project-name=campushub-landing
# 得到 https://campushub-landing.pages.dev

# 方式二：CF Dashboard → Pages → Upload assets，网页拖拽上传 index.html
```

> 注意：落地页只能做**外部宣传**，不能放进小程序 webview（个人主体无业务域名功能 + 备案要求）。

## 二、推荐成本路径（本项目适用）

| 阶段 | 方案 | 月费用 | 说明 |
|---|---|---|---|
| 开发 + 体验版调试 | CloudBase **免费体验版** | **¥0** | 3,000 资源点/月，开发阶段无需续费可持续使用 |
| 正式上线（小流量） | CloudBase **个人版** | **¥19.9** | 40,000 资源点/月，校园级流量通常够用 |
| 流量增长后 | 基础版/专业版 | 按需 | 控制台开用量告警，超了再升档 |
| 对外宣传落地页 | Cloudflare Pages | ¥0（可选） | 见 1.4 |

### 2.1 免费体验版关键事项

- 每个没有云开发环境的账号可免费创建**一个**环境（2025-02-19 起政策）
- 官网活动页标注截止 **2025-12-31**——创建环境时**以控制台实际显示为准**；若入口已下线，开发阶段按量付费对小流量几乎不产生费用
- 小程序**发布上线后免费环境有 15 天宽限期**，之后需转付费套餐 → 上线前记得开通个人版
- 配额同基础套餐，开发调试完全够用

### 2.2 省钱实操建议

1. 开发阶段用免费体验版，把 37 个云函数、索引、触发器全部部署调通
2. 在云开发控制台**开通资源点用量告警**
3. 上线前评估真实流量：校园级（几百~几千日活）个人版 ¥19.9/月足够
4. 数据库定时备份（`backup-db`，每日 03:00）本身消耗少量资源点，属于必要开销

## 三、一句话总结

> **Cloudflare 免费套餐救不了小程序后端（备案是硬墙），但本项目根本不需要它——微信云开发的免费体验版覆盖整个开发阶段（¥0），上线后每月 ¥19.9 封顶；CF 留着白嫖一个对外宣传落地页就够了。**
