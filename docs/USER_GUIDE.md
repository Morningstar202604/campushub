## 1. 产品概述

CampusHub 是一个基于 **微信小程序 + 微信云开发** 的全国性校园 / 兴趣内容社区，定位"开箱即用的开源贴吧"。核心能力：

| 模块 | 说明 |
|------|------|
| 多级分类 | 分区 → 吧 → 子版块（3 级），后台可视化维护，用户发帖必须选到叶子节点 |
| 信息流首页 | 瀑布流双列，推荐 / 最新 / 二手 Tab，分类筛选，置顶展示 |
| 贴吧式发帖 | 图文、标签、匿名、任务类型、有效期、草稿、图片预览 |
| 二手交易 | 商品发布、价格 / 成色 / 交易方式、收藏、标记已售、下架 |
| 楼中楼评论 | 主楼层 + 子回复、评论点赞、回复 @某人、删除 |
| 关注系统 | 关注 / 取关、粉丝 / 关注列表、用户主页 |
| 每日签到 | 连续签到 + 积分（每 7 天加成） |
| 站内通知 | 点赞 / 评论 / 关注自动通知，未读红点 |
| 内容安全 | 文本 + 图片 fail-closed 审核（审核失败即拒绝发布） |
| 管理后台 | 举报审核、封禁、置顶、加精、分类 CRUD、认证审核 |
| 任务过期 | 任务 / 求助设有效期，超时自动归档到"过期任务"页 |
| 全站搜索 | 帖子 / 商品 / 指南三合一，关键词高亮、历史记录、热门搜索 |

**技术栈**：原生微信小程序 + TDesign 组件库 + 微信云开发（34 个云函数 + 16 个数据集合 + 云存储）。

## 2. 角色与权限

| 角色 | 判定方式 | 能力 |
|------|---------|------|
| **游客** | 未登录（无本地登录态） | 浏览首页、帖子、商品、指南、广场、搜索；不能发布 / 评论 / 点赞 / 收藏 / 签到 |
| **普通用户** | 微信授权登录并填写昵称等资料 | 游客全部能力 + 发帖、评论、点赞、收藏、关注、签到、举报、反馈、发布商品、编辑自己的内容 |
| **校园认证用户** | 提交认证并审核通过（`campusVerified: true`） | 普通用户全部能力 + 帖子 / 商品展示「🎖️ 已认证」标识（交易信任标识） |
| **管理员** | openid 在云函数环境变量 `ADMIN_OPENIDS` 中，或 `config` 集合 `adminOpenids` 数组中 | 普通用户全部能力 + 管理后台（举报审核、置顶加精、封禁解封、认证审核、删除任意内容、分类管理） |

> 说明：本项目**不区分"超级管理员"**，管理员权限由 `ADMIN_OPENIDS` 统一控制；`category-manage` 分类管理同样按管理员权限放行。封禁仅影响内容发布（被禁用户 `requireActiveUser` 直接拒绝），历史内容保留。

**权限边界（云端强制）**：
- 所有写操作走云函数并在云端校验身份，前端无法绕过；
- 只能编辑 / 删除**自己**的内容（或管理员）；
- 点赞 / 收藏 / 关注 / 签到依赖唯一索引 + 幂等插入，重复点击不会产生脏数据；
- 所有 UGC 文本与图片发布前都过内容安全审核（fail-closed）。

## 3. 快速上手

**首次使用流程（约 1 分钟）**：

1. 打开小程序 → 进入**首页**（可先浏览公开内容）；
2. 点击底部导航「我的」→ 点击「点击登录」→ 进入**登录页**；
3. 在登录页填写 **昵称**（必填）、**学院 / 专业 / 年级**（建议填）、**兴趣标签**（选填），勾选同意《用户协议与隐私政策》后点击「进入校园通」；
4. 回到「我的」，可进行：**每日签到**、**校园认证**、**编辑资料**；
5. 点击首页右下角「＋」或顶部「🔍」开始发布与搜索。

> 登录后建议尽快完成**校园认证**（见 4.16），二手交易买家 / 卖家更信任带「已认证」标识的账号。

## 4. 页面使用手册

> 各页面均通过底部 TabBar（首页 / 二手市场 / 表白墙 / 我的）或顶部入口进入。以下按入口顺序逐一说明。

### 4.1 首页（index）

**入口**：小程序启动默认页。

**功能**：信息流聚合首页，瀑布流双列展示帖子；顶部功能区；分类筛选；发布菜单。

| 界面元素 | 操作 | 说明 |
|---|---|---|
| 顶部「🔍 搜索」条 | 点击 | 进入**搜索页**（搜帖子 / 商品 / 指南） |
| 顶部「⏰ 过期」 | 点击 | 进入**过期任务**页 |
| 顶部「💌 墙」 | 点击 | 进入**表白墙** |
| 顶部「📂 全部分类」 | 点击 | 打开**多级分类选择器**（分区 → 吧 → 子版块），筛选该分类下的帖子 |
| 分类筛选「✕ 清除」 | 点击 | 清除分类筛选，回到全部分类 |
| 「推荐 / 最新 / 二手」Tab | 切换 | 推荐（综合排序 + 置顶）、最新（按时间）、二手（商品流） |
| 帖子卡片 | 点击 | 进入**帖子详情**；显示置顶徽章、标签、点赞数 |
| 右下角「＋」 | 点击 | 展开**发布菜单** |
| 发布菜单「📝 发帖子」 | 点击 | 进入**发帖子**页（普通 / 任务类型） |
| 发布菜单「🛒 卖东西」 | 点击 | 进入**发布商品**页 |
| 发布菜单「🎒 失物招领」 | 点击 | 进入**失物招领**页 |
| 发布菜单「💌 表白墙」 | 点击 | 进入发帖子页并预选「表白墙」类型（匿名） |
| 发布菜单「取消」 | 点击 | 收起发布菜单 |

**操作步骤**：
- 浏览：上下滑动信息流，切换 Tab，点分类筛选后浏览；下拉刷新、上滑加载更多。
- 发布：点「＋」→ 选类型 → 按对应页面操作。
- 需要登录才能发布（游客点「＋」会提示登录）。

### 4.2 登录页（login）

**入口**：「我的」→「点击登录」；或游客触发需登录的操作时自动跳转。

**功能**：首次登录注册（微信授权 + 资料填写）。

| 界面元素 | 操作 | 说明 |
|---|---|---|
| 昵称输入框 | 输入 | **必填**，空昵称会被拒绝 |
| 学院 / 专业输入框 | 输入 | 选填，建议填写 |
| 年级选择器 | 点击 | 下拉选择年级 |
| 兴趣标签 | 点击 | 选填，多选 |
| 《用户协议与隐私政策》 | 勾选 | **必须勾选**才能登录 |
| 协议链接 | 点击 | 查看协议全文 |
| 「进入校园通」按钮 | 点击 | 提交登录注册 |

**注意**：登录后昵称等资料可在「编辑资料」页修改；登录采用云函数 `login`，同一微信自动识别老用户。

---

### 4.3 搜索页（search）

**入口**：首页顶部「🔍」、二手市场顶部「🔍」。

**功能**：全站搜索（帖子 / 商品 / 指南三合一），关键词高亮，历史记录，热门搜索。

| 界面元素 | 操作 | 说明 |
|---|---|---|
| 搜索输入框 | 输入 + 回车 / 点「搜索」 | 执行搜索 |
| 「✕」清除按钮 | 点击 | 清空关键词与结果 |
| 结果 Tab「帖子 / 商品 / 指南」 | 切换 | 切换结果分类，显示各分类命中数 |
| 结果卡片 | 点击 | 进入对应**详情页**；标题中关键词**高亮**显示 |
| 「搜索历史」+「清空」 | 点击 | 展示最近 10 条历史；一键清空 |
| 「热门搜索」标签 | 点击 | 直接用该词搜索 |

**操作步骤**：输入关键词 → 点搜索（或回车）→ 查看结果 → 点击进入详情。

**注意**：搜索受 2 秒客户端限频保护；相同关键词且已有结果时直接复用不重复请求。

### 4.4 发帖子（post-publish）

**入口**：首页「＋」→ 发帖子 / 表白墙；表白墙页「✍️」；失物招领页「丢了 / 捡到」。

**功能**：发布图文帖子，支持类型选择、有效期、标签、匿名、草稿、编辑已有帖子。

| 界面元素 | 操作 | 说明 |
|---|---|---|
| 分类选择器 | 点击 | 打开多级分类选择器，**必须选到最细（叶子）分类** |
| 类型选择「💬 普通帖 / 📌 任务请求 / 🔍 失物 / 🎁 招领 / 💌 表白墙」 | 点击 | 决定帖子类型（失物 / 招领 / 表白墙由入口预选） |
| 有效期选择器 | 点击 | 仅任务 / 请求类型可选（3 / 7 / 15 / 30 天），超时未解决自动归档到「过期任务」 |
| 标题输入框 | 输入 | 必填，≤30 字 |
| 内容输入框 | 输入 | 普通帖 ≤2000 字，表白墙 ≤500 字 |
| 图片选择 | 点击 | 最多 9 张，本地压缩后上传；可预览、可删除 |
| 话题标签 | 输入 + 添加 | 最多 5 个，`#标签` 形式展示 |
| 地点输入框 | 输入 | 选填，展示在帖子详情 |
| 匿名开关 | 开启 | 匿名发布（显示「匿名同学」，可发帖可评论，**不可发布商品或交易**） |
| 「发布 / 保存修改」按钮 | 点击 | 提交发布（编辑态为保存修改） |

**操作步骤**：选分类 → 选类型（可选有效期）→ 填标题内容 → 传图 → 加标签 → 点「发布」。

**草稿机制**：离开页面时自动保存草稿，下次进入自动恢复，发布成功后清除。

**注意**：所有文本 + 图片发布前经内容安全审核（fail-closed），审核失败会提示拒绝发布。

**操作步骤**：浏览正文 → 点赞 / 收藏 / 关注 → 下拉评论区 → 发评论或回复 @ → 按需分享 / 举报 / 编辑 / 删除。

### 4.11 失物招领（lost-found）

## 5. 功能模块详解

### 5.1 内容安全（fail-closed）
- 发帖、评论、反馈、举报、商品发布的**所有文本与图片**，发布前调用微信内容安全接口审核；
- **审核失败即拒绝**（fail-closed），不降级放行；图片仅接受本云存储 `cloud://` 链接，拒绝外链；
- 涉及政治 / 涉黄 / 暴力 / 广告等违规内容会被拦截，违规严重者由管理员封禁。

### 5.2 点赞 / 收藏 / 关注
- 帖子、商品、评论均支持点赞；帖子与商品支持收藏；用户间可互相关注；
- 依赖唯一索引 + `insertIdempotent` 幂等：**重复 / 并发点击不会产生重复数据**，也不会双倍计数。

### 5.3 楼中楼评论
- 评论分主楼层与子回复（楼中楼）；`≤2 条`子回复默认展开，更多时折叠可展开；
- 支持对评论点赞、回复 @某人（可取消）、删除自己的评论。

### 5.4 每日签到与积分
- 每日可签到一次（按北京时间日期），连续签到递增积分：`n + floor(连续天数/7)*5`（每满 7 天额外 +5）；
- 依赖 `(user, date)` 唯一索引防重复签到（并发不双倍积分）。

### 5.5 任务系统
- 发帖可选「任务 / 请求」类型并设有效期（3 / 7 / 15 / 30 天）；
- 定时云函数（每 6 小时）自动把超时未解决的任务归档到「过期任务」页；
- 作者可随时标记「✅ 已解决」。

### 5.6 二手交易
- 商品发布需登录且**不能匿名**；价格必须为合法非负数字，原价不能低于售价；
- 支持成色（如 全新/几乎全新/轻微使用/明显使用/破损）、交易方式（面交/邮寄等）；
- 卖家可标记已售 / 恢复上架 / 下架；列表仅展示在售商品。

### 5.7 匿名机制
- 匿名仅适用于**发帖（表白墙等）与评论**，商品发布强制真实昵称；
- 匿名帖显示「匿名同学」，帖子详情显示「匿名」标识与「✅ 已送达」徽章；
- 匿名仅隐藏昵称，作者仍可在「我的列表」管理自己的匿名帖。

### 5.8 通知
- 点赞 / 评论 / 关注自动生成站内通知；「我的消息」显示未读红点，进入后自动已读。

### 5.9 搜索
- 三合一（帖子 / 商品 / 指南），关键词高亮；保存最近 10 条搜索历史；内置热门搜索词；
- 2 秒客户端限频，防止高频搜索拖垮后端。

### 5.10 访问控制与限流
- 写操作统一 `requireActiveUser`（登录 + 封禁拦截）；
- 发帖 / 评论 / 反馈 / 举报 / 点赞等均有服务端限流（如 30 秒 1 条、10 秒 20 次等），防刷屏；
- 浏览量去重（`view_logs` + 内存窗口），一次会话只计一次。

## 6. 管理后台操作手册

> 管理后台 = 「我的」→「🛡️ 管理后台」。权限：`ADMIN_OPENIDS` 环境变量（逗号分隔 openid）或 `config` 集合 `adminOpenids`。

### 6.1 举报审核（默认 Tab「举报审核」）
1. 查看待处理举报列表（总数显示在顶部「待处理举报：N」）；
2. 每条举报含：被举报内容摘要、说明、被举报作者昵称；
3. 操作：
   - **「删除内容」**：删除违规帖子 / 商品 / 评论（软删除，作者侧也消失）；
   - **「封禁作者」**：封禁该内容作者（禁止发布，可后续解封）；
   - **「标记处理」**：将举报标记为已处理（无违规时放行）。

### 6.2 帖子管理（置顶 / 加精）
1. 在输入框粘贴**帖子 ID**（帖子详情页右上角操作栏可见，或从举报列表复制）；
2. 点击 **「📌 置顶」**（帖子在首页信息流置顶展示）/「取消置顶」；
3. 点击 **「⭐ 加精」** /「取消加精」。

### 6.3 用户封禁 / 解封
- 输入用户 openid 或从举报列表选择作者 → **「封禁」**（禁止发布内容）/ **「解封」** 恢复。

### 6.4 校园认证审核
- 查看待审核申请（总数「待审核申请：N」），含申请人、学校、学号、证件照片（点击可预览）；
- 点击 **「✅ 通过」** / **「❌ 驳回」**（驳回可填原因，申请人侧可见）。

### 6.5 分类管理
- 见 4.21：新增 / 编辑 / 删除分类，维护 3 级分类树与校区归属。

## 8. 常见问题 FAQ

**Q1：游客能做什么？**
浏览所有公开内容（首页、帖子、商品、指南、表白墙、失物招领、搜索）。发布 / 评论 / 点赞 / 收藏 / 关注 / 签到均需登录。

**Q2：登录后显示"点击登录"？**
可能登录态被清除或用户信息缺失，重新走一次登录流程即可。

**Q3：发帖总被拒绝？**
文本或图片未通过内容安全审核（fail-closed）。请检查是否包含违规、广告、外链图片等内容。

**Q4：找不到「管理后台」入口？**
只有 openid 在 `ADMIN_OPENIDS` 环境变量中的账号可见该入口。联系部署方将你的 openid 加入后重新进入小程序。

**Q5：发帖选不了分类？**
分类必须选到**叶子节点**（子版块）。若没有可选项，说明分类树未初始化或该校区无叶子分类，请联系管理员在分类管理中维护。

**Q6：任务自动消失/跑到过期页了？**
任务 / 求助设了有效期，超时未解决会自动归档到「过期任务」页，不再推上主页。

**Q7：二手商品搜索不到/列表看不到？**
列表只展示**在售**商品；已售 / 下架商品不在列表，可在「我的列表-已售」查看自己的。

**Q8：匿名发帖还能被识别吗？**
匿名仅隐藏昵称（显示「匿名同学」），但内容仍受平台管理；作者可在「我的列表」管理自己的匿名帖。

**Q9：积分有什么用 / 怎么获得？**
每日签到获得积分：`1 + 连续天数加成`（每满 7 天 +5）。积分在用户主页展示，为社区活跃度信用体系（当前版本暂未开放积分消费）。

**Q10：如何成为管理员？**
由部署方把你的微信 openid 加入云函数环境变量 `ADMIN_OPENIDS`（逗号分隔）或 `config.adminOpenids`，重新进入小程序即可看到管理后台入口。
