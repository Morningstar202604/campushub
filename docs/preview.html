CampusHub 交互原型 v2

基于 gitcode.com/badhope/campushub v0.8.1 真实源码重构，含 23 个核心页面。

纠正的偏差

  • tabBar 还原为 首页/二手/指南/我的
  • 首页改为双列瀑布流（原为单列）
  • 首页 tab 改为 推荐/热门/最新
  • 主色改为源码真实的 #4A90D9

使用者视角设计

  • 买家：蓝 V 认证标识、折扣对比、交易安全提示
  • 卖家：成色/原价/交易方式、认证增益提示
  • 失主：地点筛选、"我捡到了"双向按钮、已找回态
  • 学生：指南已核验标、积分签到、任务帖到期提醒
  • 管理员：举报/认证/反馈待办数、审计日志

操作

  • 点击卡片进详情，点 tabBar 切主页面
  • 点右下角 + 打开发布面板
