# CampusHub v2 — 全流程测试报告（QA）

> 环境：无后端（Supabase 未配置）· mock 数据模式 · 浏览器自动化（真实点击/输入/上传）
> 日期：2026-09-24 · 结论：**学生端全功能按真人使用流程跑通，测试中发现的 12 类问题全部修复**

---

## 一、测试方法

- 学生端以 `VITE_USE_MOCK=true` 构建，`vite preview` 本地托管（端口 5199）
- 用浏览器自动化按**真人使用顺序**操作：真实点击、真实输入、真实上传文件、坐标点击（等价手指点击）
- 每步操作后读取页面文本/截图验证状态变化
- mock 数据（点赞/收藏/评论/发帖/签到/已读）持久化到 localStorage，刷新页面验证不丢失

## 三、测试中发现并修复的问题

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 未配置 Supabase 时**整站白屏** | `createClient('')` 直接抛错中断模块链 | `lib/supabase.ts` 用非空占位符降级，页面正常渲染、数据区空态 |
| 2 | 首页/市集**首屏不加载**（一直"加载中"） | 依赖 van-list 的 immediate-check，该机制在部分环境不触发 | onMounted 主动加载首屏，van-list 只做滚动加载更多 |
| 3 | 切"最新/热榜"**列表不刷新** | tab 切换无监听 | 加 `@change` 重置并重新加载 |
| 4 | 收藏计数显示 **NaN** | mock 帖子缺 `collect_count` 字段，`undefined + 1` | mock 归一化默认 0 |
| 5 | 评论/我的帖子**作者显示错误**（显示"阿沐"） | mock PROFILES 的 key 是 `me`，查询用 `mock-me`，回退到默认用户 | key 统一 `mock-me` |
| 6 | 分类显示 **"undefined 闲聊树洞"** | mock 分类用 `icon` 字段，前端用 `emoji` | 补 `emoji` 字段 |
| 7 | 失物/表白墙**无法提交**（提示"请选择分类"） | 这两场景表单无分类选择器，但提交强校验分类 | 按场景固定默认分类（cat_lost / cat_confess） |
| 8 | 市集分类栏显示**全部 8 个分类** | 直接用了全部分类 | 过滤只显示"二手闲置"及其子分类 |
| 9 | 消息页**无"全部已读"**、点单条全标已读 | 设计缺陷 | 顶部加"全部已读"按钮（有未读才显示），点击单条只跳详情 |
| 10 | 意见反馈用 **window.prompt** 系统对话框 | 实现粗糙 | 改为 Vant 弹层表单（textarea + 字数限制） |
| 11 | mock 状态**刷新即丢**（收藏/发帖丢失） | 纯内存态 | 点赞/收藏/关注/评论/发帖/签到/已读统一持久化到 localStorage |
| 12 | mock 登录态**刷新丢失** | auth restore 未处理 mock | mock 下从 localStorage 恢复演示登录态 |
| 13 | 帖子/商品**举报用 window.prompt** 系统对话框 | 实现粗糙 | 两个详情页均改为 Vant 弹层表单（textarea + 字数限制 + 必填校验） |
| 14 | **签到后积分显示 0、连续天数变 0**（我的页变未登录） | `fetchProfile()` 缺少 mock 分支，签到后调用它把 profile 置 null | fetchProfile 增加 mock 分支，从持久化资料恢复 |
| 15 | **编辑资料/签到积分刷新即丢** | mock-me 资料不在持久化范围内 | state 新增 `me` 字段并纳入 localStorage 持久化，签到/编辑资料/作者昵称全部走 `state.me` |

## 四、自动化测试环境注意事项（复现时参考）

1. **浏览器缓存会坑人**：修改代码重新构建后，务必带时间戳访问（如 `http://localhost:5199/?v=<时间戳>#/`），否则可能还在跑旧页面。
2. **真实点击 vs JS click**：本环境 `element.click()` 不触发 Vue 事件委托，点赞/收藏等互动必须用坐标点击或 ref 点击模拟真人。
3. **mock 开关**：`localStorage.campus_mock='1'`（运行时）或 `VITE_USE_MOCK=true`（构建时）二选一；关闭=删 localStorage 或非 mock 构建。
4. **重置 mock 数据**：`localStorage.removeItem('campus_mock_state_v1')` 后刷新回到种子数据。
